# Feedback

Thirdminute is currently being developed by Hex at 550W Lab.

## What is welcome

Questions, suggestions, and feedback on the project are welcome through
[GitHub Issues](https://github.com/550w-lab/thirdminute/issues).

When test builds become available, reports of unexpected behaviour will be
especially useful. Please describe what you expected, what happened, and how
to reproduce it.

## Code contributions

External code contributions and pull requests are not being accepted at this
stage. Please use issues to describe problems or proposed improvements.

The preview's rights notice is in [LICENSE](LICENSE). Any future software
release will have its own applicable terms.
